# Fuentes inmobiliarias

El panel permite configurar diez fuentes. La fuente institucional consulta el catálogo público de circulointernacionalveracruz.org. Las demás fuentes activas se buscan únicamente en sus dominios permitidos.

Los anuncios deben tener precio publicado, ubicación, tipo, operación y una liga directa observada en la fuente. Las características ausentes quedan por confirmar. No se muestran demostraciones ni anuncios vendidos.

La consulta devuelve coincidencias y alternativas con diferencias explícitas. Las ligas seleccionadas por el cliente se incluyen en el reporte enviado cuando solicita contacto.

No se eluden autenticación, CAPTCHA, restricciones ni condiciones de uso. Una fuente inaccesible se informa como cobertura parcial.
